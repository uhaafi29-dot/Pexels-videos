# Voiceover placeholders

Record each line as its own file, drop it in this folder and pass the file
names to the composition (see the project README). Lines start ~0.2 s after
the scene begins, so keep each read inside its window.

| Scene | Window | Prop key | Line |
| --- | --- | --- | --- |
| 1 | 0.0–4.0 s | `intro` (optional) | "Why does change feel so difficult?" |
| 2 | 4.2–9.0 s | `familiar` | "Repeated behaviors can become easier and more automatic." |
| 3 | 9.2–15.0 s | `newRoute` | "New behaviors often require more attention and practice." |
| 4 | 15.2–20.0 s | `repetition` (optional) | "Repetition helps new habits become familiar." |

Delivery: calm, warm documentary narrator, ~140 words per minute.
Each line above runs about 3–4 s at that pace.
